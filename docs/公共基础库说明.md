# 后端公共基础说明

这份说明给后续业务模块开发使用，主要覆盖登录态、当前用户、统一返回、分页和操作日志。

## 1. 登录态

登录接口：

```http
POST /api/users/login
```

成功后返回：

```json
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "...",
    "tokenType": "Bearer",
    "user": {
      "id": 1,
      "username": "test",
      "roles": ["USER"]
    }
  }
}
```

后续请求统一带请求头：

```http
Authorization: Bearer 登录返回的token
```

前端 `src/api.js` 已经加了 axios 拦截器，调用 `loginUser` 后会自动保存 token，后续通过默认导出的 `api` 实例请求会自动带上登录态。

## 2. 当前登录用户

业务接口需要当前用户时，Controller 方法参数这样写：

```java
@GetMapping("/example")
public ApiResponse<?> example(@CurrentUser AuthenticatedUser currentUser) {
    Long userId = currentUser.getId();
    return ApiResponse.success("查询成功", userId);
}
```

常用字段：

```java
currentUser.getId()
currentUser.getUsername()
currentUser.getRoles()
currentUser.hasRole("ADMIN")
```

建议业务模块优先使用当前登录用户，不要让前端传 `userId` 决定数据归属。

## 3. 统一异常

Controller 里可以直接抛异常：

```java
throw new IllegalArgumentException("题目不存在");
throw new ForbiddenException("只能操作自己的数据");
throw new UnauthorizedException("请先登录");
```

统一异常处理器会转成 `ApiResponse.fail(...)`，并设置合适的 HTTP 状态码。

## 4. 分页返回

JPA 查询得到 `Page<T>` 后可以这样返回：

```java
return ApiResponse.success("查询成功", PageResponse.from(pageData));
```

返回字段：

```json
{
  "records": [],
  "total": 0,
  "page": 1,
  "size": 10,
  "totalPages": 0
}
```

## 5. 操作日志

需要记录关键动作时注入 `OperationLogService`：

```java
operationLogService.record("QUESTION_CREATE", "新增题目：" + title);
```

如果当前没有登录上下文，也可以显式传用户 ID：

```java
operationLogService.record(userId, "USER_REGISTER", "用户注册：" + username);
```

日志会写入数据库里的 `operation_log` 表。

## 6. 公共接口

```http
GET /api/health
GET /api/users/me
PUT /api/users/me/profile
PUT /api/users/me/password
```

除注册、登录和健康检查外，`/api/**` 默认都需要登录态。

## 7. 分类与标签接口

分类接口用于给资源、知识卡片、题目分组：

```http
GET /api/categories?keyword=高数
GET /api/categories/{categoryId}
POST /api/categories
PUT /api/categories/{categoryId}
DELETE /api/categories/{categoryId}
```

新增或修改分类的请求体：

```json
{
  "name": "高等数学",
  "description": "高数课程资料",
  "parentId": null
}
```

标签接口用于给资源、知识卡片打标：

```http
GET /api/tags?keyword=重点
GET /api/tags/{tagId}
POST /api/tags
PUT /api/tags/{tagId}
DELETE /api/tags/{tagId}
```

新增或修改标签的请求体：

```json
{
  "name": "重点",
  "description": "需要优先复习的内容"
}
```

前端 `src/api.js` 已经封装了 `listCategories`、`createCategory`、`listTags`、`createTag` 等方法，业务页面可以直接导入使用。
