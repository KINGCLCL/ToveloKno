# 题目管理后端接口

基础路径：`/api/questions`

除注册、登录外，项目中的业务接口都需要请求头：

```http
Authorization: Bearer <登录接口返回的 token>
```

## 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/questions` | 分页、组合筛选题目 |
| GET | `/api/questions/stats` | 题目总数、已发布、草稿、回收站统计 |
| GET | `/api/questions/{id}` | 查询题目详情 |
| POST | `/api/questions` | 新增题目 |
| PUT | `/api/questions/{id}` | 修改题目 |
| DELETE | `/api/questions/{id}` | 移入回收站 |
| POST | `/api/questions/batch-delete` | 批量移入回收站 |
| PUT | `/api/questions/batch/status` | 批量发布或转为草稿 |
| PUT | `/api/questions/{id}/restore` | 恢复回收站题目 |
| DELETE | `/api/questions/recycle-bin/{id}` | 永久删除回收站题目 |

## 分页筛选参数

`GET /api/questions` 支持：

- `page`：从 1 开始，默认 1
- `size`：默认 10，最大 100
- `keyword`：搜索题干、科目和知识点
- `subject`、`knowledgePoint`
- `categoryId`：按分类 ID 精确筛选，同时包含它的所有子分类
- `questionType`
- `difficulty`：1～5
- `status`：`DRAFT` 或 `PUBLISHED`
- `deleted`：`false` 查正常题目，`true` 查回收站
- `sort`：`createdAt`、`updatedAt`、`difficulty`、`status`、`questionType`
- `direction`：`asc` 或 `desc`

## 新增、修改请求示例

```json
{
  "content": "数据库事务具有什么特性？",
  "questionType": "SINGLE_CHOICE",
  "options": ["A. 原子性", "B. 随机性", "C. 临时性"],
  "correctAnswer": "A",
  "analysis": "事务具有 ACID 特性。",
  "difficulty": 3,
  "subject": "数据库",
  "knowledgePoint": "事务管理",
  "status": "PUBLISHED",
  "categoryId": null
}
```

题型编码：`SINGLE_CHOICE`、`MULTIPLE_CHOICE`、`TRUE_FALSE`、`FILL_BLANK`、`SHORT_ANSWER`。

选择题至少需要两个选项。判断题没有传选项时，后端会自动生成“正确、错误”。

## 数据库升级

- 全新数据库：执行 `backend/src/main/resources/db/schema.sql`
- 已初始化过旧版数据库：执行 `backend/src/main/resources/db/migration-question-management.sql`

接口只会查询和操作当前登录用户创建的题目；批量操作中只要包含无权限题目，整次事务就会拒绝执行。
