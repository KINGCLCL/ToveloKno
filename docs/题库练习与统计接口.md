# 题库练习、统计与设置接口

基础路径：`/api/question-bank`。所有接口都需要 Bearer Token，并只访问当前用户的题目与学习记录。

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/practice/questions` | 按模式、分类、知识点和数量生成练习 |
| POST | `/practice/answers` | 提交答案、自动判题并维护错题本 |
| GET | `/dashboard` | 今日练习、连续天数、最近答题和薄弱知识点 |
| GET | `/analytics` | 题库覆盖率、正确率、趋势、题型和知识点统计 |
| GET | `/settings` | 查询当前用户的题库设置 |
| PUT | `/settings` | 保存题库名称、练习数量和展示偏好 |

## 生成练习

```json
{
  "mode": "random",
  "count": 10,
  "categoryId": null,
  "knowledgePoint": null
}
```

模式包括：

- `free`：自由练习
- `chapter`：按科目、知识点顺序练习
- `random`：随机练习
- `wrong`：待掌握错题
- `weak`：正确率最低的知识点
- `challenge`：四星、五星题目

返回的练习题不包含正确答案和解析。

## 提交答案

```json
{
  "questionId": 12,
  "userAnswer": "A",
  "mode": "random"
}
```

错误答案会新增或累加错题记录；在 `wrong` 模式中答对后，该错题会标记为已掌握。

## 数据库升级

- 全新数据库：执行 `backend/src/main/resources/db/schema.sql`
- 已初始化数据库：执行一次 `backend/src/main/resources/db/migration-question-bank-interaction.sql`
